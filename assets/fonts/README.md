# Bundled font

`NotoSansSymbols2-Regular.ttf` is Noto Sans Symbols 2, downloaded from the
official `notofonts/noto-fonts` repository. It is used for the Unicode chess
glyphs U+2654 through U+265F so rendering does not depend on system fonts.
