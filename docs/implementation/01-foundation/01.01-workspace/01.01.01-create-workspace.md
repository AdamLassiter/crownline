# Task 01.01.01: Create workspace crates

Replace the single-package stub with a workspace containing the Bevy desktop client, `crownline_core`, `crownline_protocol`, and `crownline_server`.

## Dependencies

- None.

## Acceptance criteria

- `cargo check --workspace` succeeds.
- Each crate has a documented responsibility and minimal public surface.
- Core compiles with default features disabled and has no platform-service dependency.
- Client startup opens a titled window; server startup can run without graphics libraries.

## Cross-cutting concerns

- Preserve one-way dependency flow: client/server -> protocol/core.
