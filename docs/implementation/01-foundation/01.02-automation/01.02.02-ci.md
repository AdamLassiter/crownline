# Task 01.02.02: Add cross-platform CI

Create a CI matrix for quality checks and native client/server builds.

## Status

- [x] Done

## Implementation notes

- Added a GitHub Actions matrix for Linux, Windows, and macOS on pinned Rust 1.95.
- CI installs Linux native dependencies, caches Cargo outputs by lockfile/toolchain, and runs format, Clippy, and tests.
- Workflow permissions are read-only and no secret is required for pull requests.

- Pull requests run format, lint, test, scenario validation, and build jobs.
- OS-specific dependencies are installed explicitly.
- Cargo caches are keyed by lockfile and toolchain.
- CI does not require secrets for untrusted pull requests.
