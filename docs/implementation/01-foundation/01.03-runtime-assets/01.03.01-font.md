# Task 01.03.01: Bundle the Unicode chess font

Bundle an OFL-licensed font covering U+2654 through U+265F, record its source and license, and load it through Bevy assets.

## Status

- [x] Done

## Implementation notes

- Bundled Noto Sans Symbols 2, its complete OFL license, upstream attribution, and a recorded SHA-256 digest.
- The Bevy startup screen loads the bundled font and renders all six Unicode chess silhouettes with a player tint.
- The client monitors the font asset's load state; failure hides the glyph text and displays an ASCII message using Bevy's embedded default font rather than panicking.
- A focused visibility-state test covers the failure transition.

## Dependencies

- 01.01.01.

## Acceptance criteria

- All six silhouettes render for both player tints on every target OS.
- Missing/corrupt font errors produce a readable fallback screen rather than a panic.
- License and attribution files ship with releases.

## Cross-cutting concerns

- Asset licensing, readability, and platform consistency.
