# Task 02.01.02: Validate scenario invariants

Build a validator that returns all discoverable scenario errors in one report.

## Dependencies

- 02.01.01.

## Acceptance criteria

- Validation covers bounds, duplicate IDs, overlaps, impassable deployment, complete armies, castling paths, Pawn directions, Keep exits, and supported timing ranges.
- Shipped-map policy rejects overlapping settlement and promotion sites.
- Validation output points to coordinates and field names.
- Validator has positive and negative fixture tests.

## Cross-cutting concerns

- Never panic on authored or downloaded data.
