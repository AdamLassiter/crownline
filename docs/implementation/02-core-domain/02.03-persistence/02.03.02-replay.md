# Task 02.03.02: Define action journals and replay

Record accepted actions with actor, revision, idempotency key, and deterministic transition metadata.

## Dependencies

- 02.02.02, 02.03.01.

## Acceptance criteria

- Replaying from the same initial scenario yields the recorded final hash.
- Duplicate idempotency keys do not apply twice.
- Replay reports the first divergent revision and expected/actual hash.
- Journals omit credentials and presentation-only events.

## Cross-cutting concerns

- Auditability, bounded record size, and forward compatibility.
