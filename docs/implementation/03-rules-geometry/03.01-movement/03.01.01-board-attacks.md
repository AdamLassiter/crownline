# Task 03.01.01: Implement board queries and attack maps

Create bounded coordinate operations, occupancy queries, rays, jumps, and geometric attack maps.

## Dependencies

- 02.02.01.

## Acceptance criteria

- Coordinate operations cannot wrap or escape the board.
- Rays stop at the first relevant blocker and include protected friendly-occupied endpoints.
- Attack queries identify attacker IDs and lines, not only a Boolean.
- Table tests cover corners, edges, blockers, and both player orientations.

## Cross-cutting concerns

- Avoid allocation in inner ray traversal where practical.
