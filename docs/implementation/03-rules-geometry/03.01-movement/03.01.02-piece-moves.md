# Task 03.01.02: Implement piece pseudo-legal movement

Generate Queen, Rook, Bishop, Knight, King, and forward-oriented Pawn moves before King-safety filtering.

## Dependencies

- 03.01.01.

## Acceptance criteria

- Sliding, stepping, leaping, Pawn advance, and diagonal Pawn capture match chess geometry.
- Pawns never retreat and use each scenario's fixed forward direction.
- Pawn non-captures require an empty destination; captures require an enemy or valid en-passant target.
- Tests cover all six types for both players.

## Cross-cutting concerns

- Movement rules remain data-independent except for scenario geometry and toggles.
