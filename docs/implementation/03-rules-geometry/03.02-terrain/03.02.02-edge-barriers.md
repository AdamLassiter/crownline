# Task 03.02.02: Implement rivers and walls

Represent rule-affecting boundaries as canonical edges and enforce crossing restrictions.

## Dependencies

- 03.02.01.

## Acceptance criteria

- Non-Knight movement cannot cross rivers except at bridges/fords or walls except at gates/supported fortification routes.
- Knights ignore intervening blocked edges because they leap.
- Opposite representations of the same shared edge cannot disagree.
- Orthogonal and diagonal crossing cases have explicit tests.

## Cross-cutting concerns

- Scenario validation normalizes edges before hashing.
