# Task 03.02.03: Implement Rook fortification projection

Allow a Rook on a compatible friendly fortification square to cross one designated adjacent friendly wall segment and continue its ray normally.

## Dependencies

- 03.02.02.

## Acceptance criteria

- Scenario data explicitly links the tower, owner, wall edge, and projection direction.
- Only the occupying friendly Rook gains the route.
- Normal blockers and forests still stop the projected ray.
- Leaving, capturing, or replacing the Rook immediately removes the route.

## Cross-cutting concerns

- Projection affects movement, attacks, governance, and check identically.
