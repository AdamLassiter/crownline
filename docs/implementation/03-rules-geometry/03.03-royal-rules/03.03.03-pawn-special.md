# Task 03.03.03: Implement Pawn double-step and en passant

Add scenario-enabled opening double-steps and immediate-reply en-passant captures.

## Dependencies

- 03.03.01.

## Acceptance criteria

- Only an original deployed, unmoved Pawn on an allowed start square may double-step.
- Both traversed and destination squares and edges must be legal and empty.
- En passant is available only to the opponent's immediately following command and removes the correct Pawn.
- Settlement-produced Pawns can never double-step.

## Cross-cutting concerns

- En-passant availability participates in canonical hashing and repetition state.
