# Story 04.04: Clocks and outcomes

As players, we need optional fair timing and unambiguous ways for a match to end.

## Tasks

- [04.04.01 Implement optional chess clocks](04.04.01-clocks.md)
- [04.04.02 Implement draws, resignation, and outcomes](04.04.02-outcomes.md)

## Dependencies

- 04.03, 03.03.01.

## Acceptance criteria

- Untimed remains the default; configured clocks use base 1-180 minutes and increment 0-60 seconds.
- Online time is authoritative and local time is saveable.
- Every terminal state is immutable and names its reason and winner where applicable.

## Cross-cutting concerns

- Keep clock mechanics outside deterministic move generation while persisting authoritative values.
