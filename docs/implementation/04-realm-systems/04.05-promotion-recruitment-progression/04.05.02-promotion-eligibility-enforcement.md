# Task 04.05.02: Enforce promotion eligibility

Snapshot and enforce the promotion kinds unlocked by current realm control.

## Status

- [ ] Not started

## Dependencies

- 04.05.01, 04.03.01, 04.03.02, 02.02.02.

## Scope

- Refactor owner-turn processing to resolve settlement transfers, advance settlement cycles, and identify matured promotion candidates before calculating one realm-control snapshot and queuing the batch.
- Store the frozen score, score breakdown, and deterministically ordered allowed kinds on each queued `MandatoryChoice::Promote`.
- Derive cumulative choices from the scenario thresholds: Knight always, then Bishop, Rook, and Queen when their respective thresholds are met.
- Validate `Action::ChoosePromotion` against the queued snapshot rather than recalculating live control after each choice.
- Add a typed locked-kind transition error containing the requested kind, frozen score, and required threshold without mutating state.
- Provide shared deterministic legal-action enumeration for mandatory promotion choices so clients, tests, replays, and the future AI opponent use the same set.
- Include the frozen eligibility snapshot in canonical state equality, hashing, and repetition identity.

## Acceptance criteria

- Knight is legal at every score; threshold table tests cover scores 1/2, 3/4, and 7/8.
- Settlement transfers and establishment completed on the boundary contribute immediately to the batch snapshot.
- Losing current control changes later batches but never rewrites a queued choice.
- Every promotion queued at one boundary receives the same score and allowed kinds.
- Resolving an earlier promotion cannot unlock Rook or Queen for another choice in that batch.
- A locked promotion request returns the typed error and leaves canonical state unchanged.
- Legal-action enumeration never includes a locked kind and remains stable across repeated calls.

## Cross-cutting concerns

- Transactional reducer behavior, stable ordering, complete-state repetition, explainable errors, and no second rules authority in UI or AI code.
