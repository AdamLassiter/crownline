# Epic 05: Authored scenarios

Create three deliberate, symmetric maps that exercise the complete ruleset at different match lengths.

## Stories

- [05.01 Introductory scenario](05.01-intro/05.01-story.md)
- [05.02 Standard scenario](05.02-standard/05.02-story.md)
- [05.03 Large scenario](05.03-large/05.03-story.md)

## Dependencies

- 02.01, Epic 03, Epic 04.

## Acceptance criteria

- Every scenario passes schema, reachability, opening-route, symmetry, and complete-army validation.
- Terrain is sparse and every feature creates a visible strategic choice.
- Each side can contest at least one meaningful feature within its first several turns.

## Cross-cutting concerns

- Competitive symmetry, readability, target duration, and data-only balance changes.
