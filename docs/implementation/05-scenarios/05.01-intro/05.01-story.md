# Story 05.01: Introductory scenario

As a new player, I need a readable map that teaches the interaction between chess, settlements, promotion, and terrain.

## Tasks

- [05.01.01 Author the 16x16 layout](05.01.01-layout.md)
- [05.01.02 Validate the learning path](05.01.02-validate.md)

## Dependencies

- 02.01, Epic 04.

## Acceptance criteria

- The map has full armies, four settlements, two promotion sites, two Keeps, one river with two crossings, two small forests, and one mountain pass.
- The expected match length is 30-45 minutes.
- No single opening route dominates both central objectives.

## Cross-cutting concerns

- Reduce visual density without changing core rules.
