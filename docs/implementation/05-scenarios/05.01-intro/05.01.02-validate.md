# Task 05.01.02: Validate the introductory learning path

Exercise scripted openings and human playtests to verify early contact and mechanic discoverability.

## Dependencies

- 05.01.01, 07.02.02.

## Acceptance criteria

- A contested settlement or crossing can be reached within the first several turns by both sides.
- Testers can identify why governance advances or pauses using only the board and side panel.
- No Keep permits immediate forced mate from the initial position.
- Findings and data-only adjustments are recorded.
