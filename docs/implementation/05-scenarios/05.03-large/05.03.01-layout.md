# Task 05.03.01: Author the 24x24 layout

Create a rotationally symmetric large scenario with deliberately separated but interacting theatres.

## Dependencies

## Acceptance criteria

- Multiple routes connect every theatre; no side can seal all crossings permanently with one piece.
- Long files and diagonals create valuable governance and attack tradeoffs.
- Promotion sites remain contestable from more than one approach.
- Full-army deployments and castling routes validate.

## Cross-cutting concerns

- Keep terrain sparse enough to read at fit-to-window zoom.
