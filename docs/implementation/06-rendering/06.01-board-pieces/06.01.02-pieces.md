# Task 06.01.02: Render Unicode pieces

Render U+2654-U+2659 silhouettes with the bundled font and player-specific text colors.

## Dependencies

- 01.03.01, 06.01.01.

## Acceptance criteria

- All types are centered, consistently sized, and legible on every terrain tint.
- Player identity also has an optional outline/backplate cue.
- Piece entities update by stable piece ID across movement and promotion.
- Missing glyph detection produces a visible diagnostic fallback.

## Cross-cutting concerns

- Do not rely on Unicode white/black glyph fill to encode ownership.
