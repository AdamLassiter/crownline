# Task 06.02.01: Implement coordinate conversion and picking

Create tested functions converting canonical coordinates to world positions and cursor rays back to optional board squares.

## Dependencies

- 06.01.01.

## Acceptance criteria

- Corners, borders, negative world coordinates, and out-of-board clicks behave correctly.
- Conversion is independent of window DPI and camera zoom.
- Board orientation is explicit and labels agree with Pawn directions.
- Headless tests cover representative transforms.

## Cross-cutting concerns

- Do not derive rule coordinates from rendered entity iteration.
