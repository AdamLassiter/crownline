Add fit-to-board, cursor-centered wheel zoom, drag/keyboard pan, reset, and responsive resize behavior.

## Status

## Implementation notes

- Added a camera-control plugin that initially fits any 16x16, 20x20, or 24x24 authored board inside 90% of the available viewport and resets to the same centered fit.
- Wheel or remappable keyboard zoom clamps to 0.25-2.0 orthographic scale. Cursor zoom shifts the camera center analytically so the same world point remains beneath the pointer.
- Middle/right drag and normalized keyboard pan share one controller. Pan bounds retain at least one full tile inside the viewport, preventing the complete board from being lost.
- The controller reads current logical window dimensions every frame. Resize therefore preserves the current world focus where valid and reapplies bounds without an unnecessary recenter.
- Camera bindings are Serde-backed client settings with remappable up/down/left/right, zoom-in/out, and reset actions; defaults are WASD, E/Q, and F, with arrow and plus/minus alternatives supported.
- `PointerCapture` suppresses board hover, wheel zoom, and drag while UI owns the pointer. Keyboard camera actions remain available for accessibility.
- Camera changes are direct and contain no forced tween or shake, so reduced-motion mode never receives animated camera motion. Pure math fixtures cover authored-map fitting, cursor anchoring, board-retaining clamps, and alternate key mapping.

## Acceptance criteria

- Zoom has readable min/max bounds and preserves the pointed board location.
- Pan cannot lose the entire board off-screen.
- Resize preserves focus where possible and keeps UI usable.
- Controls have keyboard equivalents and are remappable.

## Cross-cutting concerns

- Camera motion respects reduced-motion settings.
