# Task 06.03.01: Build overlay layers

Render selected square, legal Move/Hold context, capture targets, attacks, check, governors, blockers, and previewed gains/losses.

## Dependencies

- 06.01.03, 06.02.01, 03.03.01, 04.01.01.

## Acceptance criteria

- Overlay precedence is deterministic and documented.
- Hover preview distinguishes new and lost attacks/governance.
- Check and illegal self-check warnings cannot be hidden by ordinary highlights.
- Overlay recomputation occurs only when relevant state changes.

## Cross-cutting concerns

- Provide a legend and accessible textual equivalent in the side panel.
