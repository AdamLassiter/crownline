## Implementation notes

- Piece parents snap immediately to canonical coordinates. A nested presentation child receives the old-to-new offset and eases visually to zero over 180ms, leaving picking and overlays anchored to the authoritative destination throughout.
- Removed/captured identities despawn their interactive `PieceVisual` immediately and may leave a 160ms presentation-only ghost. Promotion therefore retires the Pawn ghost and creates the new promoted identity without making either obsolete visual selectable.
- Reduced-motion settings and an explicit fast-forward resource skip movement tweens and retirement ghosts while preserving the same canonical state and entity identity updates.
- `TransitionEventQueue` accepts already ordered core transition events. Concise notices and the durable `TransitionNoticeLog` preserve that order for simultaneous settlement, production, promotion, turn-start, and terminal effects; fast-forward skips only transient notice entities.
- Notice and movement systems never gate action application or input. Animation timers only mutate presentation children/ghosts and remove themselves when complete.
- Tests cover monotonic no-overshoot interpolation, fast-forward at the canonical destination with no tween, and deterministic multi-event realm summary order.

## Acceptance criteria

- Canonical entities update immediately; animation interpolates presentation only.
- Fast-forward/reduced-motion skips animation without changing results.
- Multiple start-of-turn events display in deterministic order.
- Input cannot accidentally target an obsolete visual position.

## Cross-cutting concerns

- Keep animations brief and avoid combat spectacle that obscures outcomes.
