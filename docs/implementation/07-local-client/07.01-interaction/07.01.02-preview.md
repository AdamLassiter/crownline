# Task 07.01.02: Implement consequence preview

Use the core preview API to show captures, new/lost attacks, opened/closed lines, check exposure, governance interruption, and promotion changes before confirmation.

## Dependencies

- 07.01.01, 06.03.01, 04.01.02.

## Acceptance criteria

- Preview is derived from a non-mutating reducer simulation.
- Lost settlement progress opportunity and changed governors are named in text as well as highlighted.
- Illegal self-check destinations can be inspected as unavailable with a reason but not submitted.
- Preview never persists after state revision or selection changes.

## Cross-cutting concerns

- Do not calculate or display strategic recommendations or evaluation scores.
