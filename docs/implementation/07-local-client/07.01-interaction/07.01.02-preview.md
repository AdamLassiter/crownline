# Task 07.01.02: Implement consequence preview

Use the core preview API to show captures, new/lost attacks, opened/closed lines, check exposure, governance interruption, and promotion changes before confirmation.

## Dependencies

## Status

- [x] Done

## Implementation notes

- `inspect_move` is a read-only core boundary that distinguishes unreachable movement from a pseudo-legal destination that would expose the active King. The client uses this typed result to explain unavailable self-check hovers without duplicating board geometry or permitting submission.
- Legal hover previews run the same transactional `apply_action` reducer used for committed commands against the current immutable state. Tests compare canonical hashes before and after preview to guard against mutation.
- Preview overlays and text identify captures, newly opened and closed attack lines, resulting check, and every settlement whose governor identity set changes. Added and removed governor IDs and authored settlement names are included in the textual equivalent.
- Ordered transition events supply explicit settlement continuity/development loss, development advance, promotion candidate start/advance/cancellation, and promotion-ready explanations. Lost settlement progress opportunity is named directly rather than inferred only from color.
- Preview cache identity includes canonical revision, selection, and hover. Selection removal clears all preview text and overlays; revision changes force recomputation from the new canonical state.
- The preview reports consequences only. It contains no scoring, ranking, recommendation, or evaluation path.
- Tests cover typed self-check inspection, legal/unreachable destination classification, non-mutating reducer preview, selection clearing, cache invalidation by revision, and text for capture, progress loss, and promotion changes.

## Acceptance criteria

- Preview is derived from a non-mutating reducer simulation.
- Lost settlement progress opportunity and changed governors are named in text as well as highlighted.
- Illegal self-check destinations can be inspected as unavailable with a reason but not submitted.
- Preview never persists after state revision or selection changes.

## Cross-cutting concerns

- Do not calculate or display strategic recommendations or evaluation scores.
