# Task 07.01.03: Implement mandatory-choice controls

Present focused, keyboard-operable controls for promotion type and produced-Pawn placement.

## Dependencies

- 07.01.01, 04.03.02.

## Status

- [x] Done

## Implementation notes

- A non-empty `ResolvingChoices` queue takes exclusive control before normal board selection, Move, or Hold handling. Only the first canonical queue entry can submit, and accepted choices use `apply_action` plus the normal ordered transition-event boundary.
- Choice text states `1 of N remaining` and identifies the Pawn or settlement for the current entry. An empty resolving phase remains fail-closed with board commands disabled rather than falling through to ordinary interaction.
- Promotion presents colored Unicode Queen, Rook, Bishop, and Knight glyphs from the bundled chess font alongside explicit names and numbered keyboard controls. Escape explains that the choice is mandatory instead of dismissing it.
- Produced-Pawn placement markers are spawned only for the `legal_squares` carried by the reducer's `MandatoryChoice::PlacePawn`. Arrow keys cycle within that stable set, Enter confirms, and pointer activation outside it is rejected with an explanation.
- Choice presentation is rebuilt by canonical revision. Selection is cleared while resolving, board focus moves only among legal placement squares, and Hold reports the mandatory-choice blocker until the reducer returns to `Command` phase.
- When canonical clocks are active, both North and South remaining times remain in the interaction label throughout choice resolution; the display rounds partial seconds upward so visible time does not reach zero early.
- Tests cover all four promotion glyph/name controls, explicit queue position, placement-focus wrapping, exact reducer-provided highlight identity, choice-time clock formatting, and the combined-plugin runtime regression recorded as Bug 005.

## Acceptance criteria

- Current choice and queue position are explicit.
- Promotion shows Queen, Rook, Bishop, and Knight glyphs with names.
- Pawn placement highlights only reducer-provided legal adjacent squares.
- Board Move/Hold controls stay disabled until the queue is empty.

## Cross-cutting concerns

- Active clocks remain visible during choice resolution.
