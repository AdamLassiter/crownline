# Task 07.01.03: Implement mandatory-choice controls

Present focused, keyboard-operable controls for promotion type and produced-Pawn placement.

## Dependencies

- 07.01.01, 04.03.02.

## Acceptance criteria

- Current choice and queue position are explicit.
- Promotion shows Queen, Rook, Bishop, and Knight glyphs with names.
- Pawn placement highlights only reducer-provided legal adjacent squares.
- Board Move/Hold controls stay disabled until the queue is empty.

## Cross-cutting concerns

- Active clocks remain visible during choice resolution.
