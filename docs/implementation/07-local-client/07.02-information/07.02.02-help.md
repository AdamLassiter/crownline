# Task 07.02.02: Build rules help and legends

Provide concise in-client explanations for chess movement, terrain, governance, development, production, promotion, Hold, clocks, and outcomes.

## Dependencies

- 07.02.01.

## Status

- [x] Done

## Implementation notes

- `F1` and the persistent Rules & legend button open a screen-space help surface without leaving or replacing the match. Escape and an explicit Close button dismiss it, and navigation buttons expose overview, movement/terrain, realm systems, match rules, and the board legend.
- Movement help covers every chess piece, authored castling routes, Pawn direction, double-step, en passant, terrain ray/placement effects, edge crossing, Knight exceptions, and diagonal component boundaries. Enabled/disabled switches and castling-route count come from the active scenario.
- Realm help explains geometric governors, founder/occupancy/continuity requirements, scenario-specific reset-versus-pause behavior, establishment/production/promotion cycle thresholds, produced-Pawn placement, and forced promotion choices using active scenario values.
- Match help explains Move versus Hold, Hold's check/choice constraints, clock charging and increment behavior, checkmate/timeout/resignation/draw/repetition outcomes, terminal immutability, and the non-recommending preview boundary.
- The board legend names light/dark parity; Open, Forest, Mountain, and Road tints; North/South piece plates; Keeps, settlements and ownership emblems, promotion X marks, fortification towers; River, Bridge, Ford, Wall, and Gate bands/labels; and every symbol/description supplied by the renderer's 12-entry overlay legend.
- Match and settlement panels contain context buttons that open their relevant section. A regression test activates a live context link and verifies the canonical match hash is unchanged.
- Generated text names only implemented game systems. Tests assert active-scenario switches/thresholds, every terrain/edge/feature/overlay legend entry, absence of out-of-scope mode claims, and state-preserving context navigation.

## Acceptance criteria

- Help content matches implemented defaults and scenario-configurable exceptions.
- A board legend explains every shape, edge, tint, and overlay.
- Context links open the relevant help section without losing match state.
- Text avoids implying unimplemented AI, faction, or campaign features.

## Cross-cutting concerns

- Documentation behavior is verified when rules change.
