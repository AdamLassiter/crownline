# Story 07.03: Local match lifecycle

As local players, we need to configure, pause, persist, resume, and conclude a match safely.

## Status

- [x] Done

## Implementation notes

- Task 07.03.01 provides validated local setup, authored scenario selection with renderer rebuild, pause/settings, confirmed resignation, draw handling, exact outcomes, and fresh rematch sessions.
- Task 07.03.02 integrates optional host-owned monotonic clocks through setup, mandatory choices, pause, actions, expiration, panels, and rematches.
- Task 07.03.03 adds bounded, versioned, atomic platform-local save slots with full pre-mutation validation, recovery guidance, pending-phase restoration, and round-trip coverage.

## Acceptance criteria

- Hot-seat setup supports scenario, player colors/names, and optional clock configuration.
- A complete match can end, display its reason, and start a rematch.
- Saves restore an identical canonical hash and pending UI phase.

## Cross-cutting concerns

- Confirm resignation/abandonment; never silently overwrite a good save.
