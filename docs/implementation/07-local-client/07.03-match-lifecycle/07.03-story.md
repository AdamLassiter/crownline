# Story 07.03: Local match lifecycle

As local players, we need to configure, pause, persist, resume, and conclude a match safely.

## Tasks

- [07.03.01 Build setup and end screens](07.03.01-setup-end.md)
- [07.03.02 Integrate local clocks](07.03.02-local-clocks.md)
- [07.03.03 Implement atomic save/load](07.03.03-save-load.md)

## Dependencies

- 07.01, 07.02, 02.03, 04.04.

## Acceptance criteria

- Hot-seat setup supports scenario, player colors/names, and optional clock configuration.
- A complete match can end, display its reason, and start a rematch.
- Saves restore an identical canonical hash and pending UI phase.

## Cross-cutting concerns

- Confirm resignation/abandonment; never silently overwrite a good save.
