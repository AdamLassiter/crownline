# Task 07.03.02: Integrate local clocks

Host optional clocks locally with untimed default, 1-180 minute base, and 0-60 second increment.

## Dependencies

- 04.04.01, 07.03.01.

## Acceptance criteria

- Clocks run through mandatory choices, pause in explicit pause state, and stop at terminal outcome.
- Increment applies only after accepted Move/Hold.
- Closing/saving does not consume offline time.
- Expiration prevents a later local command from being accepted.

## Cross-cutting concerns

- Use monotonic runtime timing and avoid frame-rate-dependent subtraction.
