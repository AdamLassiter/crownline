# Task 07.03.03: Implement atomic save/load

Provide manual save slots/files and load validation using the versioned core envelope.

## Dependencies

- 02.03.01, 07.03.02.

## Acceptance criteria

- Save includes scenario, state, action history, clock values, and application/schema versions.
- Write-to-temporary, validate, and atomic-replace protects the previous file.
- Load errors preserve the file and present recovery guidance.
- Round-trip covers pending promotion/placement, check, draw offer, and terminal state.

## Cross-cutting concerns

- Save paths are platform appropriate and user-selected exports cannot escape explicit user intent.
