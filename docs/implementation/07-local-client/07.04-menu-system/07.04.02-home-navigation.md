# Task 07.04.02: Implement Home and top-level navigation

Build the Home route and connect Local, Continue/Load, Guided, Online, Settings,
Help, and Quit destinations.

## Status

- [x] Done

## Implementation notes

- The client now opens on a dedicated Home page whose visible controls route to
  Local, Guided, Online, Settings, Rules, local saves, and confirmed Quit
  destinations.
- Home is built inside the exclusive full-window menu shell and reports the
  application version without exposing build internals.
- Continue/Load checks all three bounded save slots through the existing
  validated decoder and is visibly disabled with an explanation when none can
  be read.
- Escape and Back use one bounded navigation stack, and Quit uses an explicit
  destructive confirmation modal.
- Headless coverage verifies startup routing and every Home destination.

## Dependencies

- 07.04.01, 07.03.03, 14.01.02.

## Acceptance criteria

- Every destination is reachable by pointer and keyboard.
- Continue is enabled only when at least one readable local slot exists and
  explains the unavailable state otherwise.
- Quit and live-match abandonment require explicit confirmation.
- Back navigation is deterministic and never leaves multiple menu roots visible.
- Returning Home clears transient menu state without silently discarding a
  match.

## Cross-cutting concerns

- Discoverability, confirmation of destructive actions, and bounded navigation.
