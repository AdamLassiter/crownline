# Task 07.04.05: Implement transactional Settings

Add Display, Accessibility, Controls, and Online settings tabs backed by a
validated draft with explicit Apply and Cancel behavior.

## Status

- [ ] Not started

## Dependencies

- 07.04.01, 01.03.02, 06.02.02, Bug 010.

## Acceptance criteria

- Existing settings files remain compatible without a schema migration.
- Display offers window-size presets plus validated custom width and height.
- Accessibility offers UI scale from 0.75 to 2.5 and Reduced Motion.
- Controls capture the seven existing Shift-modified camera bindings, reject
  conflicts, and reset to defaults.
- Online settings edit the default server URL and confirm forgetting a saved
  seat.
- Apply persists valid settings; Cancel restores all previewed values; a failed
  save preserves the prior configuration and reports an actionable error.

## Cross-cutting concerns

- Compatibility, recoverability, readable scaling, and shortcut conflict
  prevention.
