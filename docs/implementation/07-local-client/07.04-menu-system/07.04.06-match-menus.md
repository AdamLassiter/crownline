# Task 07.04.06: Implement match and persistence menus

Move local and online lifecycle, save/load, and outcome actions into
context-aware GUI menus.

## Status

- [ ] Not started

## Dependencies

- 07.04.03, 07.04.04, 07.04.05, 07.03.03, 09.03.02.

## Acceptance criteria

- Local pause stops local clocks; an online menu blocks local input while
  explicitly warning that the authoritative clock continues.
- Three slot cards show Empty, Valid, or Unreadable and available scenario,
  player, revision, and outcome metadata.
- Save/load is unavailable for guided and online matches with an explanation.
- Overwrite, active-match replacement, resignation, and abandonment require
  confirmation.
- Loading restores the same canonical hash and pending phase as direct load.
- Draw, resignation, rematch, leave, and outcome controls cannot submit twice
  while pending.

## Cross-cutting concerns

- Atomic persistence, protocol authority, destructive confirmation, and clock
  truthfulness.
