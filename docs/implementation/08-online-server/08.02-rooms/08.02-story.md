# Story 08.02: Rooms and seat authority

As players, we need simple private rooms without accounts while keeping each seat secure.

## Status

- [x] Done

## Implementation notes

- Task 08.02.01 provides accountless create/join routes and a credential-bound room lifecycle covering readiness, match start, lobby leave, canonical terminal state, and rematch.
- Task 08.02.02 replaces temporary seat keys with high-entropy issued secrets, SHA-256-only storage, constant-time digest comparison, redacted representations, indistinguishable authentication failures, and throttling.
- Task 08.02.03 adds configurable body, request, room, connection, and failed-operation limits plus bounded bookkeeping and pre-game-only idle cleanup.

## Acceptance criteria

- Host configures scenario and clock; play starts only when both seats are occupied and ready.
- Room codes locate rooms but cannot authorize actions.
- Reconnect and abandoned-room behavior is deterministic and documented.

## Cross-cutting concerns

- Enumeration resistance, rate limiting, secret redaction, and bounded resource use.
