# Task 08.02.01: Implement create/join/ready flow

Add accountless room creation, second-seat join, readiness, match start, leave, and terminal/rematch lifecycle.

## Dependencies

- 08.01.02, Epic 05 scenarios.

## Acceptance criteria

- Codes are short, unambiguous, case-normalized, and collision-checked.
- Host choices are validated against installed scenario hashes and clock bounds.
- A seat cannot join twice or impersonate the other player.
- Initial clocks start only after both players are ready.

## Cross-cutting concerns

- Player display names are length-limited, escaped, and not treated as identities.
