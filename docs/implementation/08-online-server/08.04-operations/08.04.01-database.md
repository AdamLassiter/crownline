# Task 08.04.01: Create SQLite schema and migrations

Define migrations for rooms, seats/token hashes, matches, canonical snapshots, revisions, clocks, outcomes, and append-only actions.

## Dependencies

- 08.01.02, 08.02.02.

## Acceptance criteria

- Foreign keys, uniqueness, and revision constraints enforce core relationships.
- Migrations run forward exactly once and fail safely.
- Database paths and durability pragmas are configured explicitly.
- Tests create and migrate a fresh temporary database.

## Cross-cutting concerns

- Raw reconnect tokens and client-provided arbitrary blobs are never stored.
