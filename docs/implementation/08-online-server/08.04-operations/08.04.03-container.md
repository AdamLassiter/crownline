# Task 08.04.03: Package and health-check the server

Build a minimal multi-stage Linux container with non-root execution, SQLite volume, environment configuration, and graceful signals.

## Dependencies

- 08.04.02, 01.03.02.

## Acceptance criteria

- Container has no compiler/build cache and runs as a dedicated unprivileged user.
- Health endpoint reports liveness and database readiness separately.
- SIGTERM stops acceptance, drains bounded work, and closes the database cleanly.
- Documentation covers bind/public URL, database path, logs, volume, backup, and upgrade.

## Cross-cutting concerns

- Image and dependency scanning is part of release CI.
