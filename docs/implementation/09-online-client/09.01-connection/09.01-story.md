# Story 09.01: Room connection flow

As an online player, I need to create or join a private room and recover from transient disconnects.

## Tasks

- [09.01.01 Build create/join/ready screens](09.01.01-room-ui.md)
- [09.01.02 Implement authenticated reconnect](09.01.02-reconnect.md)

## Dependencies

- 08.02, 07.03.01.

## Acceptance criteria

- Room code, seat, readiness, scenario, clock, and connection state are always clear.
- Reconnect credentials are persisted privately and can be deliberately forgotten.
- Network failures retain actionable recovery paths.

## Cross-cutting concerns

- Never place reconnect tokens in clipboard text intended for room sharing.
