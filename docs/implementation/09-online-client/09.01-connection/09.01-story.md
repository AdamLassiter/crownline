# Story 09.01: Room connection flow

As an online player, I need to create or join a private room and recover from transient disconnects.

- [x] Done

## Implementation notes

- Task 09.01.01 provides the non-blocking create/join lobby UI, installed host settings, TLS-safe server selection, normalized room codes, safe errors, credential-free invitation copying, and snapshot-gated ready presentation.
- Task 09.01.02 adds private OS-backed credential persistence with a `0600` fallback, application-restart restoration, authenticated WebSocket snapshots, bounded jittered reconnection, explicit connection states and recovery controls, and deliberate seat forgetting.
