# Story 09.02: Command synchronization

As an online player, I need my intended action submitted once and the displayed board reconciled to server truth.

## Tasks

- [09.02.01 Submit revisioned idempotent commands](09.02.01-submit.md)
- [09.02.02 Reconcile authoritative snapshots](09.02.02-reconcile.md)

## Dependencies

- 09.01, 08.01.02, 07.01.

## Acceptance criteria

- Only one gameplay request can be pending per seat.
- Duplicate delivery is safe and stale results trigger reconciliation.
- Server rejection never leaves a piece visually moved in canonical state.

## Cross-cutting concerns

- UI responsiveness may preview but must never claim an unacknowledged result is final.
