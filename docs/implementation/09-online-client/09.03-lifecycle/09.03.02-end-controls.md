# Task 09.03.02: Implement draw, resign, and rematch UI

Expose draw offer/response, confirmed resignation, terminal summary, leave, and post-match rematch negotiation.

## Dependencies

- 09.03.01, 08.02.01, 04.04.02.

## Acceptance criteria

- At most one outstanding draw offer is shown with accept/decline choices.
- Resignation requires confirmation and is disabled after terminal state.
- Rematch requires both seats, reuses room settings, and creates a new match identity/state.
- Leaving a finished room does not delete its durable result.

## Cross-cutting concerns

- Match-control messages remain separate from board-action revision handling where specified by protocol.
