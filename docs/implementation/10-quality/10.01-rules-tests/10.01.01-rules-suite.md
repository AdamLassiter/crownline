# Task 10.01.01: Build table and property tests

Create composable board fixtures and exhaustive tables for movement, terrain, King safety, realm timing, special rights, and outcomes.

## Dependencies

- Epic 04.

## Acceptance criteria

- Tests cover corners, blockers, pins, discovered checks, castling, en passant, Hold, transfer, governance interruption, production, promotion, and repetition.
- Generated legal Moves never leave the actor's King attacked.
- Invalid actions leave byte-equivalent canonical state.
- State serialization round-trips to the same canonical hash.

## Cross-cutting concerns

- Fixtures use readable coordinate notation and name the invariant under test.
