Create composable board fixtures and exhaustive tables for movement, terrain, King safety, realm timing, special rights, and outcomes.

## Implementation notes

- Added a composable board fixture with conventional `a1`-`h8` coordinates and a table-driven empty-board movement invariant covering every piece kind. Existing named tables and regression fixtures cover corners, blockers, pins, discovered checks, terrain and edge barriers, castling rights, en passant, Hold, settlement transfer/interruption/production, promotion, and threefold repetition.
- Added 64 deterministic generated games of up to 64 plies from a mixed-piece position. Every selected move comes from the stable legal-move list, must apply successfully, and must leave the acting player's King unattacked. Seed and ply are included in failures so a generated case can be retained as a regression fixture.
- Every generated state is serialized and decoded, then checked for identical canonical hash and canonical JSON bytes.
- Added a table of invalid actors, identities, bounds, promotion choices, and production placements. Every rejection is checked against the exact pre-action canonical bytes, proving the transactional API does not mutate its source state.
- Verification: all 82 `crownline_core` tests pass, including the generated invariant suite; the workspace test and strict lint gates also pass.
