# Task 10.02.01: Test server concurrency and recovery

Drive HTTP/WebSocket clients against an ephemeral server and SQLite database.

## Dependencies

- Epic 08.

## Acceptance criteria

- Tests cover create/join/ready, full actions, disconnect/reconnect, draw, resign, timeout, terminal, and rematch.
- Concurrent same-revision commands commit once.
- Duplicate idempotency requests return the original result.
- Process restart restores state/hash/revision and effective deadline.

## Cross-cutting concerns

- Assert that responses/log captures do not leak token values.
