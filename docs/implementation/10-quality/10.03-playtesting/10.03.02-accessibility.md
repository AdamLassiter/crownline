# Task 10.03.02: Audit readability and accessibility

Evaluate board and menus under color-vision simulation, UI scaling, keyboard-only input, reduced motion, and common resolutions.

## Dependencies

- 07.02, 06.03.

## Acceptance criteria

- Ownership, terrain, sites, legal moves, check, and progress remain distinguishable without hue.
- All match/menu actions are keyboard reachable with visible focus.
- Text remains readable at configured UI scales without clipping critical controls.
- Reduced motion removes interpolation while retaining ordered event feedback.

## Cross-cutting concerns

- Accessibility regressions become automated image/state tests where stable.
