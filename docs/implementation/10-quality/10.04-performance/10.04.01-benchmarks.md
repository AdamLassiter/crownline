# Task 10.04.01: Benchmark core and client hotspots

Benchmark move generation, attack/governance maps, previews, hashing, serialization, snapshot projection, and overlay rebuilding on 24x24 states.

## Status

- [x] Done

## Implementation notes

- Added a deterministic ignored release-profile benchmark over the shipped 24x24 scenario's opening, a 48-ply redistributed dense midgame, and a 12-piece sparse endgame. It reports move generation, attack/governance maps, full hover preview/overlay construction, canonical hash, JSON serialization, snapshot clone/projection, and serialized state size separately.
- Added headless Bevy measurements for an unchanged revision-cache hit and a forced canonical-revision invalidation. The cache remains keyed by scenario, revision, selection, and hover; no new cross-revision cache was introduced.
- Documented the initial hardware/build profile, measured results, allocation-producing data structures, invalidation behavior, and regression ceilings in `docs/performance-baseline.md`.
- Added `scripts/benchmark.sh` plus a weekly/manual CI job. The job runs only after the complete cross-platform quality matrix, preserving golden hashes and rules behavior before enforcing release-profile means of 10 ms for core queries, 25 ms for overlay preview, 5 ms for serialization/hash/projection/cache hits, and 30 ms for invalidated Bevy updates.
- The initial local run passes every threshold. Overlay preview is the dominant path at 10.18-17.54 ms; dense move generation is 0.58 ms, and invalidated headless Bevy updates are 0.28 ms.
