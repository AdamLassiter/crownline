# Story 11.01: Player and operator documentation

As a player or host, I need accurate instructions for installing, playing, and operating Crownlines.

## Tasks

- [11.01.01 Write player documentation](11.01.01-player-docs.md)
- [11.01.02 Write server operations documentation](11.01.02-operator-docs.md)

## Dependencies

- Epics 07-09.

## Acceptance criteria

- Documentation matches shipped UI, rules defaults, ports, configuration, and limitations.
- Local saves and online reconnect behavior are explained.
- Operator instructions include deployment, health, backup, restore, upgrade, and rollback.

## Cross-cutting concerns

- Examples contain no real credentials and commands are tested against release artifacts.
