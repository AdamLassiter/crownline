# Task 11.01.02: Write server operations documentation

Document container configuration, TLS proxy expectations, persistence volume, health checks, logging, capacity, backup/restore, migration, and graceful shutdown.

## Dependencies

- 08.04.03, 10.04.02.

## Acceptance criteria

- A new operator can launch a persistent server from the published image.
- Backup and restore steps are verified on a database with active and completed matches.
- Upgrade procedure includes compatibility check and rollback point.
- Security section covers token secrecy, rate limits, TLS, file permissions, and log handling.

## Cross-cutting concerns

- Avoid prescribing a specific cloud provider.
