# Story 11.02: Desktop and server packaging

As a player or operator, I need self-contained, verifiable release artifacts.

## Tasks

- [11.02.01 Package desktop clients](11.02.01-desktop.md)
- [11.02.02 Publish the server image](11.02.02-server-image.md)

## Dependencies

- Epic 10, 11.01.

## Acceptance criteria

- Release artifacts include binaries, scenarios, font, notices, version, and required runtime files.
- Checksums and provenance identify the source revision.
- Clean-machine smoke tests pass for each target.

## Cross-cutting concerns

- Reproducibility, signing where available, asset path portability, and no embedded credentials.
