# Task 11.02.02: Publish the server image

Build, scan, tag, attest, and publish the Linux server container for the release revision.

## Dependencies

- 08.04.03, 11.01.02, 10.04.02.

## Acceptance criteria

- Immutable version and source-revision tags are available alongside an optional moving stable tag.
- Image starts as non-root and reports healthy with a mounted test database.
- Vulnerability/license scan results meet the documented release policy.
- SBOM, digest, configuration reference, and upgrade notes accompany publication.

## Cross-cutting concerns

- Do not publish from untrusted pull-request contexts.
