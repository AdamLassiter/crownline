## Acceptance criteria

- A headless caller can request a deterministic decision from canonical scenario/state plus explicit limits.
- Search maximizes for one root player across multi-action phases and changes minimax side only when canonical active player changes.
- Results include the selected action, score, completed depth, principal variation, node/quiescence counts, stop reason, and deterministic tie-break evidence.
- Aborted or exhausted searches return only a fully completed iteration's legal result.

## Cross-cutting concerns

- Core remains authoritative; search uses transactional reducer outputs and never mutates its input state.
- Deterministic node-limited mode is the testing/baseline contract even when a host also supplies a wall-clock deadline.
