## Implementation notes

- Added deterministic fail-soft alpha-beta over immutable reducer-produced successor states, using exact mate-distance/draw scores for terminal positions and bounded evaluator scores only at the ordinary horizon.
- Added cumulative iterative deepening from depth one, preserving only the last fully completed principal variation when a node limit, deadline, or cancellation interrupts a later iteration.
- Enforced maximum depth and ordinary-node limits, deterministic node-boundary stop checks, overflow-safe score sentinels, stable `ActionKey` tie-breaking, and structured node/cutoff/stop diagnostics.
- Maximizing/minimizing ownership is selected from each canonical state's `active_player`, so consecutive promotion or Pawn-placement resolutions remain with the same player instead of alternating by search-ply parity.
- Tests cover repeatability, tactical depth-two minimax with alpha/beta cutoffs, bounded node exhaustion, deadline and cancellation without partial root moves, terminal draw scoring without heuristic evaluation, consecutive same-player promotion choices, mate-distance preference, and unchanged input hashes across success and failure paths.
