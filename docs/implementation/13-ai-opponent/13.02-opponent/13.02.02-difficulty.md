# Task 13.02.02: Define and calibrate difficulty profiles

Provide several predictable strengths using search effort and heuristic breadth rather than illegal knowledge or arbitrary move randomization.

## Status

- [x] Done

## Implementation notes

- Added versioned, serializable Apprentice, Steward, and Warden configurations with monotonically increasing ordinary depth/node limits, quiescence depth/node limits, enabled evaluation features, and optional host move-time caps.
- Apprentice uses depth 1, 500 ordinary nodes, 1/250 quiescence limits, and a 250 ms cap with advanced safety, promotion, terrain, governance, production, and transfer terms disabled. Steward uses depth 2, 8,000 nodes, 2/4,000 quiescence, and 1 second; Warden uses the full baseline evaluator at depth 4, 100,000 nodes, 4/50,000 quiescence, and 3 seconds.
- Easy play remains deterministic and legal: profiles narrow evaluation and search effort but never randomize stable tie-breaking or replace the searched action with a known-worse move.
- Added versioned per-scenario effort overrides for tutorial and challenge authors. Overrides retain the named profile's evaluation meaning and alter only explicitly supplied limits or time policy.
- Added a repeat-twice node-limited corpus covering the 16x16, 20x20, and 24x24 authored openings plus golden positions containing terrain/crossings, developed settlements, promotion and production choices, and an imminent capture. It verifies byte-equivalent decisions with no wall-clock stop; the release-profile corpus completes locally in about 1.1 seconds for ten Apprentice searches, including the 24x24 case.
- Names describe relative configured effort only and remain provisional, not claims about validated human skill. Scenario authors and UI must preserve that wording until paired human playtests exist.

## Scope

- Define named profiles such as Apprentice, Steward, and Warden with explicit maximum depth, node budget, quiescence limits, enabled evaluation components, and optional move-time cap.
- Keep stable tie-breaking at every level; easy play comes from shallow/narrow reasoning, not seeded blunders or selecting a known-worse move after search.
- Establish scenario overrides for tutorial/challenge content without changing global profile meaning.
- Build a deterministic position corpus spanning openings, captures, check, terrain chokepoints, settlement claims/governance/production, promotion, sparse endgames, and all map sizes.
- Record decision quality, nodes, completed depth, elapsed release time, and regressions against a stronger reference profile; labels remain provisional until human evidence exists.

## Acceptance criteria

- Every profile has a versioned configuration and reproducible node-limited result corpus.
- Higher profiles use a monotonic superset of search/evaluation capability unless a documented tuning experiment says otherwise.
- Apprentice responds within the interactive budget on the 24x24 corpus; stronger profiles expose progress/cancellation and bounded maximum time.
- Difficulty names are not presented as validated player skill levels until paired human playtests support them.

## Cross-cutting concerns

- Honest UX, deterministic baselines, target-hardware performance, data-driven tuning, and no hidden bonuses or rule exceptions.
