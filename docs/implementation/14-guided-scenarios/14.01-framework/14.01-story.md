# Story 14.01: Guided-play framework

As a scenario author, I need data-driven lessons and puzzles that can explain goals, track progress, and configure an AI opponent without forking the rules.

## Status

- [x] Done

## Implementation notes

- The canonical schema, bounded objective/predicate engine, non-overlapping guidance UI, separate local progress/resume storage, registered AI policies, and exact validated reply-tree path are implemented in Tasks 14.01.01-14.01.03.
- Guided content remains declarative and reducer-driven: Bevy owns presentation and local orchestration, the core owns validated starts/objectives/reply legality, and the AI crate owns closed profile/policy registries and bounded decisions.

## Acceptance criteria

- Scenario data can declare an arbitrary validated starting position, lesson stages, success/failure objectives, hints, AI seat/profile, move/turn limits, and allowed setup without executable scripting.
- Guidance reacts to typed reducer events and canonical predicates, not UI guesses or special-case rule mutations.
- Progress can save/resume locally and remains separate from canonical competitive match state/hash.
- The framework supports both open-ended tutorials and exact challenge solution trees.

## Cross-cutting concerns

- Schema migrations, deterministic predicates, bounded authored text/data, localization readiness, accessibility, and untrusted-content validation.
