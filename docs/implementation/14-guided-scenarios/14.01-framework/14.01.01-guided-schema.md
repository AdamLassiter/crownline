# Task 14.01.01: Define lesson and puzzle scenario data

Extend scenario authoring with validated guided starts and declarative learning/challenge objectives.

## Status

- [x] Done

## Implementation notes

- Added an optional schema-versioned `GuidedContent` block to the canonical scenario format. `None` is omitted during RON serialization, preserving the exact canonical hashes of all existing competitive scenarios.
- Guided starts embed a complete canonical `MatchState` plus human-seat/setup policy. Construction clones that validated state deterministically, allowing compact arbitrary pieces, realm progress/lineage, rights, side-to-act, and mandatory phases without weakening ordinary deployment validation.
- Validation bounds stage, predicate, hint, localization-key, and reply-tree data; rejects unsupported versions, invalid coordinates/mountains, malformed royal state, unknown castling rights, inconsistent settlement/Pawn/transfer/promotion lineage, invalid mandatory choices, duplicate/unreachable references, circular prerequisites, invalid limits, and malformed registered AI/reply IDs.
- Added stable declarative tutorial/challenge/open-practice metadata, stage prerequisites, localization-ready title/explanation/hint keys, action/turn limits, completion metadata, registered AI configuration IDs, and bounded reply-tree nodes without embedded executable code or a core dependency on the AI crate.
- Added read-only canonical predicates for legal moves, piece/material/terrain/survival/check/phase/outcome facts, settlement ownership/governance/establishment/production, and typed move/capture/crossing/terrain/realm/promotion/terminal events. Stage evaluation applies bounded action/turn failure before failure predicates and conjunctive success predicates.
- Tests prove deterministic guided-start hashes, live/save/replay objective parity, typed transition evaluation, invalid starts/schema/cycles, and unchanged legacy scenario serialization/hashes.

## Dependencies

- 02.01.01, 02.01.02, 04.04.02, 05.01.01.

## Scope

- Add an optional versioned guided-content block while preserving existing competitive scenario hashes when absent.
- Support validated arbitrary piece/realm/rights/phase starts needed for compact demonstrations and puzzles, distinct from full-army competitive deployment validation.
- Define stable lesson stage IDs, title/explanation/hint keys, prerequisites, success/failure predicates, turn/action limits, side-to-act, AI configuration, and completion metadata.
- Express predicates from canonical facts/events: legal move/capture/check, crossing, terrain interaction, claim/govern/establish/produce/transfer, promotion, survival, material condition, and terminal outcome.
- Reject impossible coordinates, inconsistent royal/special rights, invalid realm lineage, circular stages, unreachable references, unbounded text/data, and unsupported predicates.

## Acceptance criteria

- One schema represents competitive, tutorial, and puzzle scenarios without weakening validation for existing maps.
- Guided starts construct a valid canonical state and hash deterministically.
- Objectives evaluate identically during live play, save/load, and replay and cannot mutate rules/state.
- Schema fixtures cover success, failure, invalid starts, migration, and unchanged legacy scenario hashes.

## Cross-cutting concerns

- Backward compatibility, strict data validation, stable IDs, no embedded code, deterministic event/predicate evaluation, and bounded content.
