# Task 14.01.01: Define lesson and puzzle scenario data

Extend scenario authoring with validated guided starts and declarative learning/challenge objectives.

## Status

- [ ] Not started

## Dependencies

- 02.01.01, 02.01.02, 04.04.02, 05.01.01.

## Scope

- Add an optional versioned guided-content block while preserving existing competitive scenario hashes when absent.
- Support validated arbitrary piece/realm/rights/phase starts needed for compact demonstrations and puzzles, distinct from full-army competitive deployment validation.
- Define stable lesson stage IDs, title/explanation/hint keys, prerequisites, success/failure predicates, turn/action limits, side-to-act, AI configuration, and completion metadata.
- Express predicates from canonical facts/events: legal move/capture/check, crossing, terrain interaction, claim/govern/establish/produce/transfer, promotion, survival, material condition, and terminal outcome.
- Reject impossible coordinates, inconsistent royal/special rights, invalid realm lineage, circular stages, unreachable references, unbounded text/data, and unsupported predicates.

## Acceptance criteria

- One schema represents competitive, tutorial, and puzzle scenarios without weakening validation for existing maps.
- Guided starts construct a valid canonical state and hash deterministically.
- Objectives evaluate identically during live play, save/load, and replay and cannot mutate rules/state.
- Schema fixtures cover success, failure, invalid starts, migration, and unchanged legacy scenario hashes.

## Cross-cutting concerns

- Backward compatibility, strict data validation, stable IDs, no embedded code, deterministic event/predicate evaluation, and bounded content.
