# Task 14.01.03: Connect scenario-controlled AI opponents

Let guided content select constrained AI behavior while preserving the general AI interfaces and canonical rules.

## Status

- [ ] Not started

## Dependencies

- 14.01.01, 13.02.02, 13.02.03.

## Scope

- Resolve authored AI profile/seat/limits through the same validated difficulty registry used by ordinary Human-vs-AI play.
- Allow a lesson to select an evaluator feature subset or bounded response policy by registered ID, never embedded code or an arbitrary weight payload.
- Support deterministic authored reply sets/solution-tree replies for exact demonstrations and general alpha-beta replies for open practice.
- Validate that every authored reply is legal at its node and define deterministic fallback/error behavior if content and canonical rules drift.
- Suppress AI score/principal-variation display during challenges while retaining structured developer diagnostics.

## Acceptance criteria

- Tutorials can use a predictable teaching reply policy; open practice can use a named general difficulty.
- Challenge correctness never depends solely on a heuristic AI choosing the expected defense when other legal defenses refute the solution.
- Content version/rules drift fails validation before play rather than producing an illegal or misleading opponent move.
- AI cancellation, clocks, mandatory choices, retry, and stale-result protections remain identical to ordinary local AI play.

## Cross-cutting concerns

- Registered behavior only, deterministic replies, honest challenge validation, no executable scenario content, and reusable AI/client boundaries.
