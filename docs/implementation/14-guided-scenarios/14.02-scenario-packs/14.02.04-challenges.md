# Task 14.02.04: Author tactical and realm challenge puzzles

Create a replayable challenge set whose harder positions test Crownlines-specific planning as well as ordinary tactics.

## Status

- [x] Complete

## Dependencies

- 14.02.03, 13.02.02, 14.01.03, 10.01.02.

## Scope

- Author difficulty-banded exact puzzles for mate/check defense, capture sequences, terrain routes, promotion timing, settlement interruption/defense/transfer, production, and combined material-versus-realm choices.
- Give each puzzle an explicit success predicate, action/turn bound, allowed first moves or solution set where needed, and complete legal defensive reply tree.
- Use exhaustive bounded search for exact puzzles; use a named Warden AI profile only for open-ended survival/advantage challenges.
- Provide progressive hints that describe the relevant rule/strategic tension before revealing coordinates or actions.
- Record completion, best actions/turns, retries, and hints locally without public scores or telemetry.

## Acceptance criteria

- Every exact challenge is solvable within its bound against every declared legal defense, not merely the current AI's preferred reply.
- At least half the initial pack requires a settlement, governance, terrain, production, or promotion insight beyond ordinary chess tactics.
- Alternative valid solutions are accepted when they satisfy the canonical objective.
- Rule/search version drift invalidates and regenerates solution archives before shipping.

## Cross-cutting concerns

- Solver correctness, replayable deterministic archives, honest hints, local-only progress, content versioning, and bounded exhaustive search.

## Implementation notes

- Added six exact one-action puzzles and one bounded open challenge. The exact set covers checkmate, line capture, a bridge capture, settlement-transfer defense, alternative production placements, and deliberate Knight underpromotion at control score 8; four of six require Crownlines-specific terrain, realm, production, or promotion reasoning.
- Exact scenarios complete before an opponent reply is reachable, so their legal defense frontier is empty. The deterministic generator nevertheless enumerates every legal first action, applies each through the canonical reducer, evaluates the declared objective, and archives the complete accepted solution set with scenario/start hashes, branching factor, shortest length, and feature tags in `challenge-solutions.ron`.
- A regression test independently regenerates that exhaustive first-action frontier and rejects solution, hash, branching, or feature-coverage drift. The production puzzle intentionally archives five alternative valid placements rather than prescribing a best move.
- The only open-ended challenge uses the named Warden profile on a small six-piece settlement position. Its deterministic repeat-twice smoke verifies a legal reply within Warden's node and quiescence limits while keeping the test and client response bounded.
- Progressive hints state the relevant tension first and reveal coordinates only in the second hint. Existing guided progress records completion, best actions/turns, retry count, and hint use in the local atomic progress document; no telemetry or public scoring was added.
